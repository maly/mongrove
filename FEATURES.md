# Features

Done. These are in the current builds.

## Core

- Connection management (including SOCKS5 proxy)
- Database and collection tree
- Collection tabs
- Table, JSON, and tree views
- Inline document editing in the table
- IntelliShell
- Context menus
- Readonly mode (safe for production)
- Query bookmarks
- Import / Export CSV
- Views

## Aggregate Builder

- Visual Aggregate Builder — drag & drop stages
- Live preview of each stage
- Export pipeline to code
- IntelliSense in the Aggregate Builder

## Data exploration

- Schema tab (sample-based field types and stats)
- Generate JSON Schema from the Schema tab
- Validation rules (view and edit JSON Schema validators)
- Data Model / ERD — generate a diagram of collections, fields, and relationships; export PNG/JSON
- Visual Explain
- Visual Find Query Builder

## Developer tools

- IntelliSense in IntelliShell and query editor
- Export query to language
- Sampling controls

## Admin & ops

- Users & roles
- Real-time server stats
- SSH tunnel (local port forward, key or password)
